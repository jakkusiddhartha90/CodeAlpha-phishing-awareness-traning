## 1. Objective

The objective of this task is to develop an educational phishing-awareness module that helps users identify suspicious messages and websites, understand social-engineering techniques, and apply practical security habits.

## 2. Work completed

A responsive web-based training module was created with the following sections:

1. Introduction to phishing and common attack types.
2. Warning signs in suspicious emails, links, attachments, and websites.
3. Fictional examples showing suspicious and safer communication patterns.
4. Social-engineering tactics such as urgency, authority, trust, and curiosity.
5. Recommended protective practices, including independent verification, MFA, unique passwords, software updates, and reporting.
6. An interactive 10-question quiz with immediate feedback and a final score.

## 3. Tools and technologies

- HTML5 — content and structure
- CSS3 — layout, styling, and responsive design
- JavaScript — quiz interaction, feedback, score calculation, and navigation
- Git and GitHub — version control and project hosting

## 4. Learning outcomes

This project demonstrates an understanding of:

- Common phishing methods, including email phishing, spear phishing, smishing, vishing, whaling, and website spoofing.
- Indicators that may reveal a fraudulent message or website.
- How social engineering exploits human behavior.
- Practical steps users can take to reduce phishing risk.
- How to communicate cybersecurity concepts through an interactive learning resource.
