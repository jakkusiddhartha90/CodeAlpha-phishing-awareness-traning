# PhishGuard — Phishing Awareness Training

**Cybersecurity Internship Project | Task 2: Phishing Awareness Training**

PhishGuard is a responsive, browser-based awareness training module that teaches users how to recognize phishing, understand social engineering, follow safer practices, and test their knowledge.

> This is an educational awareness project. It does not collect credentials, send messages, track users, or contact external systems. All phishing examples are fictional and use reserved `.invalid` example domains.

## Project objectives

This project addresses the task requirements:

| Internship requirement | Where it is covered |
|---|---|
| Create a presentation or online module focused on phishing attacks | Responsive PhishGuard training website |
| Explain how to recognize phishing emails and fake websites | “Spot the signs” module and fictional email examples |
| Educate about social engineering tactics | Social engineering module |
| Provide best practices and tips to avoid falling victim | “Your everyday defense plan” module |
| Include real-world examples and interactive quizzes | Realistic fictional scenarios and 10-question quiz |

## Features

- Responsive layout for desktop, tablet, and mobile
- Six common phishing types
- Six practical phishing warning signs
- Fictional suspicious and safer email examples
- Social engineering tactics: urgency, authority, trust, and curiosity/reward
- Six practical security recommendations
- Ten-question interactive quiz with instant feedback and score
- No backend, account, or credential collection

## Run locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.

Optional: use the VS Code **Live Server** extension and choose **Open with Live Server** on `index.html`.

No package installation, API key, database, or server is required.

## Testing checklist

-  Open `index.html` in a desktop browser.
-  Check the navigation links.
-  Read each phishing type and warning sign.
-  Review both fictional email scenarios.
-  Complete all ten quiz questions.
-  Confirm the score and retake button work.
-  Open the website on a mobile-sized screen and check the menu.
-  Check the browser console for errors.

## Security and privacy notes

- The quiz runs entirely in the user's browser.
- Quiz answers and scores are not transmitted or stored.
- The sample suspicious domain uses the reserved `.invalid` top-level domain and is not a real login destination.
- Never test phishing techniques on real people or systems without explicit authorization.
- For a real organization, follow its approved incident-reporting and security policies.
